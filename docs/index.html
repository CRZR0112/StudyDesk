WHAT IT DOES

不是题库，是你的笔记整理台。

学校已经有足够的题目。知序只解决一件事：把散乱的材料变成能反复复习的结构。

01

把材料收进来

图片 OCR、PDF / DOCX / PPTX / XLSX，或直接粘贴文字。保留原始材料，方便对照。

02

拆成可复习的结构

知识脉络、学习目标、核心概念、重点、公式、易错点、例子、作答框架和翻面闪卡。

03

按你的选科归档

中三至中六、核心科与选修科（含 M1 / M2），每个账号的笔记与设置独立保存。
